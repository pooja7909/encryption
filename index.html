Substitution: each letter is swapped for a different letter. In a Caesar cipher, every letter moves along the alphabet by the same amount, called the shift.

Tip: drag the wheel to turn the inner disk by hand. The rings never swap: the outer ring is always plaintext and the inner disk is always ciphertext. To encrypt, go from outer to inner. To decrypt, go from inner to outer.

Substitution: each letter is swapped for a symbol. In Pigpen, the symbol is the shape of the space around the letter in the key below. Letters in the second grid and the second X also get a dot.

Pigpen key

Substitution, with many shifts: a keyword sets a different Caesar shift for each letter (A = 0, B = 1, … Z = 25). The keyword repeats along the message, so the same letter can turn into different ciphertext letters.

Transposition: the letters stay the same but change places. The key is the number of rows (also called rails). Write the message in a zigzag down and up the rows, then read each row from left to right.

The fence
